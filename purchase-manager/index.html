무료 키 발급받기 ↗

거래명세서나 영수증 사진을 찍었을 때 구매처·품목·수량·단가·합계금액을 자동으로 읽어오려면 Gemini API 키가 필요합니다. (한 번 입력해두면 브라우저에 안전하게 보관됩니다)

스마트폰과 사무실 PC에서 동일한 연동 코드를 입력하거나 [스마트폰 접속 링크 복사]로 카톡에 보낸 주소를 열면, 현장에서 폰으로 찍어 올린 구매내역과 거래명세서가 사무실 PC에 실시간으로 동기화됩니다.

📖 클라우드 동기화 3단계 빠른 사용법
  1. 웹 주소로 접속: Vercel이나 GitHub Pages로 배포된 인터넷 주소(URL)로 스마트폰과 PC에서 접속합니다.
  2. 동일한 연동 코드 입력: 위 칸에 나만의 코드(예: office-2026)를 적고 저장합니다. (또는 ?room=코드명 링크로 접속하면 자동 설정됨)
  3. 실시간 자동 반영: 외근 중 스마트폰으로 거래명세서를 찍어 올리면 사무실 PC 화면에 새로고침 없이 즉시 나타납니다!
💡 팁: API 키 없이도 사용 가능한가요?
네! API 키가 없어도 거래명세서/부품 사진 첨부, 원터치 구매처/품목 입력, 클라우드 동기화, 엑셀 다운로드는 100% 무료로 즉시 작동합니다.
