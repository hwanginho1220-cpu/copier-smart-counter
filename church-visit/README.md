# ✝️ 우면공동체 강현구 목사님 순심방 신청 프로그램

우면공동체 약 31개 순의 순장님들이 스마트폰으로 접속하여 일정이 겹치지 않게 순심방을 신청하고, 실시간 캘린더로 신청 현황을 확인할 수 있는 웹 애플리케이션입니다.

---

## 🌟 주요 기능

1. **신청 항목**
   - **순 이름**: 총 31개 순 (여성 1~11순, 직여 1~12순, 남성 1~8순) 원클릭 카테고리 선택 + 직접 입력 지원
   - **순장 이름**: 텍스트 입력
   - **심방 원하는 날짜**: 날짜 선택기 및 캘린더 연동
   - **심방 시간**: 시작 시간 ~ 종료 시간 (오전/오후/저녁 추천 시간 버튼 지원)
   - **심방 장소**: 순원 가정, 교회 목양실, 카페 등
   - **부가 정보**: 참석 예정 인원 및 기도제목

2. **완벽한 중복 방지 시스템**
   - **시간 충돌 방지**: 이미 다른 순이 예약한 시간대와 1분이라도 겹치면 즉각 경고 배너를 띄우고 신청 버튼이 비활성화됩니다.
   - **순 중복 신청 방지**: 동일한 순이 중복 신청하는 것을 방지합니다.
   - **당일 예약 프리뷰**: 날짜를 선택하면 그 날 이미 예약된 다른 순의 시간대를 폼 바로 아래에서 미리 보여줍니다.

3. **신청 현황 캘린더 & 타임라인**
   - 월간 달력에서 날짜별로 예약된 순 이름과 시간을 한눈에 확인
   - 날짜를 누르면 해당 일자의 상세 일정표 표시 및 "이 날짜로 바로 신청" 지원

4. **순별 전체 현황판 (총 31개 순)**
   - 여성순, 직여순, 남성순 카테고리별로 신청 완료된 순과 미신청 순을 한눈에 구분
   - 진행률 프로그레스 바 제공

5. **목사님 / 교역자 관리자 모드 (비밀번호: 1234)**
   - 전체 심방 일정 조회 및 취소/삭제
   - **엑셀(CSV) 다운로드**: 한글 깨짐 없이 엑셀에서 바로 열리는 심방 일정표 파일 생성
   - 일정표 인쇄 기능

6. **실시간 클라우드 무료 연동 (Firebase)**
   - Google Firebase 무료 티어(평생 무료 한도 충분) 연동 지원
   - 여러 순장님이 동시에 각자의 스마트폰에서 접속해도 **새로고침 없이 1초 만에 실시간 동기화**
   - 클라우드 키 설정 전에는 브라우저 로컬 저장소로 바로 동작

## 🚀 실행 방법

### 방법 1. 내 컴퓨터에서 바로 열기
`church-visit` 폴더의 `index.html` 파일을 더블클릭하여 크롬, 엣지, 웨일 등 웹 브라우저에서 바로 실행합니다.

### 방법 2. 카카오톡으로 순장님들께 링크 공유하기 (무료 배포)
순장님들이 각자의 스마트폰으로 접속하려면 아래 무료 호스팅 사이트에 올리시면 됩니다:
- **Vercel** (추천): [vercel.com](https://vercel.com)에 가입 후 `church-visit` 폴더를 드래그앤드롭하면 10초 만에 무료 웹사이트 주소(`https://xxx.vercel.app`)가 생성됩니다.
- **Netlify**: [netlify.com](https://netlify.com)에 로그인 후 폴더를 끌어다 놓기만 하면 무료 배포 완료.
- **GitHub Pages**: 깃허브 저장소에 올려 무료 호스팅 가능.

## 🔥 Firebase 무료 실시간 클라우드 연동 4단계

순장님들의 동시 접속 및 실시간 동기화를 위해 Google Firebase 무료 데이터베이스를 연결할 수 있습니다:

1. [Firebase 콘솔](https://console.firebase.google.com)에 구글 계정으로 로그인하고 **[프로젝트 추가]**를 누릅니다.
2. 좌측 메뉴 **[Firestore Database]** > **[데이터베이스 만들기]** 클릭 (규칙은 '테스트 모드' 선택).
3. 프로젝트 개요 옆 **[톱니바퀴(설정)]** > **[프로젝트 설정]** > 하단 **내 앱의 웹(&lt;/&gt;)** 클릭하여 앱 등록.
4. 화면에 나오는 `firebaseConfig`의 값(`apiKey`, `projectId` 등)을 복사하여 웹 화면 상단의 **[로컬 모드 ⚙️]** 버튼을 누르고 입력하면 즉시 실시간 동기화가 시작됩니다!
