무료 실시간 클라우드 동기화 설정

💡 실시간 동기화란?

Google Firebase의 무료 티어를 연결하면, 순장님들이 각자의 스마트폰에서 신청한 내역이 1초 만에 모든 사람의 캘린더에 실시간으로 공유되어 중복 신청이 완벽히 차단됩니다.

* 설정하지 않아도 브라우저 로컬 저장소로 즉시 사용 가능합니다.

📌 Firebase 무료 프로젝트 생성 1분 가이드

  1. Firebase 콘솔에 구글 계정으로 로그인 후 [프로젝트 추가]
  2. [Firestore Database] 메뉴에서 [데이터베이스 만들기] 클릭 (테스트 모드로 시작)
  3. 프로젝트 설정(톱니바퀴) > 웹 앱(</>) 추가 후 표시되는 `firebaseConfig` 복사
  4. 위 입력창에 붙여넣고 [저장] 누르면 즉시 실시간 연동 완료!
